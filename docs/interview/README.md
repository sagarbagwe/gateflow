Start with the user's problem, then state invariants and trade-offs. Historical
backend tests are evidence of that checkpoint; fresh frontend/mock-browser checks
are not fresh backend or production performance evidence. Do not describe planned
capabilities as shipped, or targets as measured throughput/uptime.
